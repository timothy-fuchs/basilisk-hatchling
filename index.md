This project is a miniature replica of the classic Macintosh, running Basilisk II on a Raspberry Pi Zero 2 W, and using a Waveshare 2.8" LCD display as the screen.

# Sinister but cute. Cute but sinister.
![](/media/basilisk-hatchling.png)
