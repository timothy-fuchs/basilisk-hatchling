# Things you absolutely need to obtain

Use this as a shopping checklist while gathering parts.

## 1. Maclock

Best sourced on AliExpress. Look for a listing with decent reviews. YMMV.

![Creative translation is an added bonus](/media/maclock.png)


## 2. Raspberry Pi Zero 2 W

Best sourced with the header already soldered on. If you can find a kit that includes a radiator, get it.

![Raspberry Pi](/media/pi_zero.png)


## 3. Waveshare 2.8" LCD display

![LCD Display](/media/lcd_display.png)


## 4. Raspberry Pi 12mm header extender

![extender](/media/raspberry_pi_header_extender.png)


## 5. Two angled microUSB-to-USB-C panel-mount adapters

Best sourced on AliExpress. Search term: `angled 90 microUSB to USB-C panel mount adapter`.

![Angled MicroUSB to USB-C panel mount](/media/usb_extension.png)


## 6. MicroSD extender

Best sourced on AliExpress. Search term: `microSD extension cable` or `sd card extension cable`.

![MicroSD extender](/media/sd_extension.png)


## 7. USB-C to USB hub

Best sourced on AliExpress.

![USB](/media/usb_hub.png)


## 8. PWM sound HAT (optional)

This is supposed to work, but I have not tried it. Search for `dtoverlay=audremap,pins_18_19` if you want to test this option.

![PWM](/media/pwm.png)


## 9. USB audio dongle (optional)

Best sourced on AliExpress.

![USB Audio](/media/usb_audio_dongle.png)


## 10. Power supply

Best sourced on AliExpress. Search term: `USB-C power supply`.
I've been using this one, it works fine, but it is obviously not the only option. Raspberry Pi Zero 2 W has very modest power requirements.
![Power supply](/media/psu.png)
